# 詳細レポート出力

`Output > Report output…` で、現在の測定と計算済み結果のスナップショットを開きます。先頭に測定情報・分析パラメータの一覧を置き、その後に解析ステップ別のページを並べます。

- 各ステップにレイヤー画像、エネルギー軸を持つプロファイル画像、入力元、条件表を配置します。条件やプロファイルが多い場合は続きのページへ分割します。
- 3次元スタックの画像はメイン画面で選んでいたフレームです。フレーム番号とエネルギーを明示します。マップは2次元の計算結果を表示します。
- Registrationは登録済みスタックを使います。Pre-mapのパレットと表示範囲も保持します。
- スタックの全画像平均、保存ROI、保存済みクラスタなどのプロファイルは元の数値で掲載します。PTEEは実際に照合した前処理・正規化後の参照スペクトル、多変量マップは成分スペクトルを掲載します。
- プレビューは出力用PDFそのものです。PPTXは同じページ構成を使い、条件表と文字は編集可能です。

## 出力ファイル

選択先の下に測定名と日時を持つ新規フォルダを作り、再出力時に前回のファイルを上書きしません。

| 出力 | 内容 |
| --- | --- |
| `*.pdf` / `*.pptx` | パラメータ一覧と各解析ステップの詳細ページ |
| `spectra/*_all_spectra.csv` | 全ての取得可能な集約スペクトル。I0、スタック平均、ROI、保存クラスタ、元の参照、使用した参照、全成分など |
| `spectra/*_PTEE_endmembers_spectra.csv` | RGBYの有効なチャンネルでマップ計算に実際に使った参照スペクトル |
| `spectra/*_mapping_components_spectra.csv` | 多変量マップのRGB係数が非ゼロの成分スペクトル。解析法によってファイル名の接頭辞が変わります |
| `layers/*.png` | 各レイヤーの表示用画像 |

CSVの先頭列は `energy_eV` です。全データCSVは集約スペクトルの一括出力であり、全画素のスペクトルキューブではありません。配列長がエネルギー軸と合わない場合、短い方に切り詰めて保存せずエラーを表示します。マップ別CSVには、そのマップで未使用のクラスタや成分を混在させません。

## 保存履歴との関係

新たに計算したPTEEと多変量解析については、条件と短いスペクトル配列も測定フォルダのセッションJSONに保存し、再起動後のレポートでも利用します。過去のJSONに画像しか保存されていない場合、当時の使用スペクトルや設定を確定できません。その情報は `Not recorded` と表示し、マップ別CSVを捏造しません。対象の解析を再実行すると、その実行時の情報が新たに保存されます。

必要な出力依存パッケージは `make setup`（`make run` からも実行）でvenvへ導入します。レポート生成はGUI外のワーカースレッドで行い、プレビューと出力の完了・失敗をウインドウ下部に表示します。
